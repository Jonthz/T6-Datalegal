Name 
Record data processing activity 
 
 
 

 
Created by 
Team 6 DataLegal 
Description 
Guided wizard for department heads to inventory and classify personal 
data treatment activities, including purposes and legal bases. 
Actors 
Department Head, DPO 
Extends 
None 
Preconditions 
1. Authenticated user with Department Head or DPO role. 
2. Master catalogs previously populated. 
Postconditions 
1. Activity saved in an "Active" state within the ROPA. 
2. Immutable audit record generated with timestamp. 
Flow 
1. Enter the RoT wizard. 
2. Input name, description, and responsible party. 
3. Select the legal basis and processing purpose. 
4. Inventory data categories like ID, email, or health data. 
5. Define storage locations and retention periods. 
6. Confirm details and persist the activity.

Name 
Register technical metadata of assets 
Created by 
Team 6 DataLegal 
Description 
Captures detailed technical attributes for information assets 
(Hardware, Software, Databases) associated with a processing activity. 
Actors 
DPO, Department Head 
Extends 
None 
Preconditions 
1. A Data Treatment Activity (RoT/ROPA) must already be registered. 
2. Master catalogs for Asset Types and Formats must be available. 
Postconditions 
1. Technical metadata is linked to the asset for CID (Confidentiality, 
Integrity, Availability) risk scoring. 
Flow 
1. Select a previously registered data treatment activity. 
2. Choose the Asset Type (e.g., Software, Hardware, Physical 
Infrastructure). 
3. Select the Storage Format (e.g., Spreadsheet, Database, PDF). 
4. Specify the Conservation Medium (e.g., Physical, Digital). 
5. Assign the corresponding Confidentiality Level (e.g., Restricted, 
Public). 
6. Save the technical metadata to the asset record.
