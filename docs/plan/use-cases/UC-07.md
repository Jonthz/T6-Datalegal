1. Access the "Documents" module from the main panel. 
2. Select the type of report to generate (e.g., Privacy Policy or 
ROPA). 
3. Choose the specific department or treatment activity to include. 
4. Request the PDF generation. 
5. Review the document preview.

1. Trigger the "Customize" option before final generation. 
2. Manually add or edit specific legal clauses not found in the 
standard template. 
3. Save the modified text as a document draft. 
4. Resume the main flow at Step 4.

UC008 
Name 
Manage incidents and breaches 
Created by 
Team 6 DataLegal 
Description 
Records security incidents and manages the mandatory notifications to 
the SPDP and data subjects within legal deadlines. 
Actors 
DPO, Security Manager 
Extends 
None 
Preconditions 
1. A security incident has been detected with a confirmed date and 
discovery time. 
2. Affected data categories and the volume of data subjects have been 
identified. 
 
 
 

 
Postconditions 
1. Incident is classified by impact and recorded in the immutable audit 
log. 
2. Notification status is tracked via a traffic-light scheme to ensure 
deadline compliance. 
Flow 
1. Open the "Incidents and Breaches" module. 
2. Register incident details including type, discovery date, and volume 
of affected subjects. 
3. Select the impact level (Low, Medium, High, or Critical). 
4. Trigger the automatic generation of notification drafts for the SPDP 
and Data Subjects. 
5. Review the notification content and verify the delivery to the 
intended recipients. 
6. Monitor the status traffic-light to ensure the 5-day (SPDP) and 
3-day (Subject) legal deadlines are met. 
7. Close the incident record once all legal actions are completed.
