UC001 
Name 
Manage user accounts 
Created by 
Team 6 DataLegal 
Description 
Allows the Administrator to manage the lifecycle of system users, 
including creating, editing, and deactivating accounts, as well as 
assigning roles and departmental access. 
Actors 
Administrator 
Extends 
None 
Preconditions 
1. The Administrator must be authenticated. 
2. The organizational Tenant must be active. 
Postconditions 
1. User information is updated in the central database. 
2. Access permissions are immediately applied based on the assigned 
Role. 
 
 
 

 
Flow 
1. The Administrator accesses the "User Management" module. 
2. The system displays the list of existing users for the current Tenant. 
3. The Administrator selects "Add New User". 
4. The Administrator enters: Full Name, Email, Department, and Role 
(DPO, Auditor, Dept Head). 
5. The system validates that the email is unique and the format is 
correct. 
6. The Administrator saves the user profile. 
7. The system sends an automated welcome email with login 
instructions.

UC002 
Name 
Configure organizational profile 
Created by 
Team 6 DataLegal 
Description 
Allows the Administrator or DPO to set up and update the company's 
legal identity, tax information, and designated data protection officers. 
Actors 
Administrator, DPO 
Extends 
None 
Preconditions 
1. The user must have administrative privileges. 
2. The organizational account (Tenant) must be active. 
Postconditions 
1. The company's legal metadata is updated globally. 
 
 
 

 
2. All generated legal documents will use the new profile information. 
Flow 
1. The user navigates to the "Organization Profile" settings. 
2. The system displays the current business details (Name, RUC, 
Address, Sector). 
3. The user modifies the required fields. 
4. The user designates or updates the official DPO for the organization. 
5. The system validates the tax ID (RUC) format and mandatory 
contact fields. 
6. The user saves the configuration. 
7. The system confirms the update and records the change in the audit 
log.
