Name 
Register technical metadata of assets 
Created by 
Team 6 DataLegal 
Description 
Captures detailed technical attributes for information assets 
(Hardware, Software, Databases) associated with a processing activity. 
Actors 
DPO, Department Head 
Extends 
None 
Preconditions 
1. A Data Treatment Activity (RoT/ROPA) must already be registered. 
2. Master catalogs for Asset Types and Formats must be available. 
Postconditions 
1. Technical metadata is linked to the asset for CID (Confidentiality, 
Integrity, Availability) risk scoring. 
Flow 
1. Select a previously registered data treatment activity. 
2. Choose the Asset Type (e.g., Software, Hardware, Physical 
Infrastructure). 
3. Select the Storage Format (e.g., Spreadsheet, Database, PDF). 
4. Specify the Conservation Medium (e.g., Physical, Digital). 
5. Assign the corresponding Confidentiality Level (e.g., Restricted, 
Public). 
6. Save the technical metadata to the asset record.

Perform Risk Assessment

Team 6 DataLegal 
Description 
Execution of a structured questionnaire to automatically calculate risk 
scores based on probability and impact for a treatment activity. 
Actors 
DPO, Risk Analyst 
Extends 
None 
Preconditions 
1. The treatment activity must be registered with classified data types. 
2. Numerical weights in master catalogs must be configured. 
Postconditions 
1. Risk score (1-25) is assigned and stored. 
2. Risk level (Green/Yellow/Red) is rendered on the executive 
dashboard. 
Flow 
1. Open the Risk Assessment questionnaire for a specific activity. 
2. Answer "Yes/No" questions regarding data sensitivity and business 
impact. 
3. Provide a written Rationale for the selected probability and impact. 
4. Trigger the automatic score calculation. 
5. Review the calculated score against the critical threshold. 
6. Visualize the final position in the 5x5 risk matrix.
