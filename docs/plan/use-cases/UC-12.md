Name 
Assign Remediation 
Created by 
Team 6 DataLegal 
Description 
Allows the DPO or Auditor to assign specific remediation tasks to 
responsible parties following the identification of compliance gaps, 
audit findings, or high-risk treatment activities. 
Actors 
DPO, Auditor 
Extends 
Manage Incidents and Breaches 
 
 
 

 
Preconditions 
1. A compliance gap, audit finding, or high-risk activity must be 
identified and documented. 
2. Responsible parties (Department Heads, System Administrators) 
must have active accounts. 
3. Remediation templates or action libraries should be available for 
common issues. 
Postconditions 
1. Remediation task is assigned with clear ownership and deadline. 
2. Responsible party receives notification with task details and 
priority. 
3. Task status is tracked in the system (Pending/In 
Progress/Completed). 
4. Upon completion, the associated risk score or compliance status is 
updated. 
Flow 
1. DPO/Auditor identifies a compliance issue and accesses the 
"Remediation Assignment" interface. 
2. The system displays the issue details including description, severity, 
and current risk level. 
3. DPO/Auditor defines remediation parameters (task title, priority, 
responsible party, target date, expected outcome). 
4. DPO/Auditor confirms the assignment and the system sends 
automated notification to the responsible party. 
5. Responsible party updates task status as they progress and provides 
evidence upon completion. 
6. DPO/Auditor reviews the completion evidence, approves it, and the 
system updates the associated risk score. 
 
 
 

 
7. The system records all remediation activities in the immutable audit 
log.
