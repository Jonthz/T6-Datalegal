User Story: As a Security Manager/DPO, I want to register incidents with type, 
date/time, affected data, and volume, classify their impact, and generate automatic 
notifications to SPDP and data subjects with a deadline stoplight, so that I can comply 
with the LOPDP. 
Acceptance Criteria: Given a high-impact incident, when I save it, then the system 
prepares notifications and shows a status stoplight until closed.
