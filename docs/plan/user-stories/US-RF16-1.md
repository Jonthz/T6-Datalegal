US-RF17-1 
Immutable and exportable log  
User Story: As a Security Administrator, I want all actions to be recorded in an 
immutable, queryable, and exportable log so that I can audit changes and responsibilities. 
Acceptance Criteria: Given an authenticated user, when they perform an action (login, 
create activity, change risk, approve, generate document), then the user, timestamp, 
action, affected resource, and changes are recorded, and the entry is not editable.
