Information Classification Levels 
User Story: As a DPO, I want to classify information using standardized confidentiality 
levels (Pública de Uso Interno, Pública Clasificada, Pública Reservada) so that I can 
manage information sensitivity effectively. 
Acceptance Criteria: Given that I classify an asset, when I save, then the system 
records the confidentiality level according to the client's master risk catalog.
