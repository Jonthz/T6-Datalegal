US-RF05-1 
Catalog and automatic classification 
User Story: As a DPO, I want to consolidate an inventory of categories and classify 
them (ordinary/sensitive) and by criticality (low/medium/high) to prioritize controls. So 
that I can ensure proper classification and management of data points based on their 
sensitivity and criticality. 
Acceptance Criteria: Given a data point (e.g., passport, email, health), when it is 
registered, then the system automatically classifies it and associates it with its activities.
