US-RF01-2 
Isolation by department 
User Story: As a Department Head, I want to see only information from my department 
to prevent cross-access. So that I can ensure that no other department can access 
confidential information from my own department, maintaining proper data privacy. 
Acceptance Criteria: Given a user from Dept A, when they try to access data from Dept 
B, then the system blocks access (except for DPO/Auditor).
