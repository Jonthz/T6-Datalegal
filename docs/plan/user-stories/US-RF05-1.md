Consent registration and revocation 
User Story: As a DPO, I want to register consents by purpose/legal basis with 
timestamps and revocations to demonstrate compliance. So that I can ensure the consent 
process is recorded properly and can track revocations for compliance purposes. 
 
 
 

 
Acceptance Criteria: Given a granted consent, when I query it, then I see the date, legal 
basis, purpose, and pseudonymized data subject; if there is a revocation, I see the date.
