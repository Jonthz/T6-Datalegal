US-RF32-1 
Explicit and immutable revocation 
User Story: As a Data Subject, I want to revoke my consent, especially for sensitive 
data, and have it recorded with a date and reason for auditing, so that I can ensure 
compliance with data protection regulations. 
 
 
 

 
Acceptance Criteria: Given a revocation, when it is registered, then the system 
immutably stores the date and reason, applicable to all data types, meeting the 
requirements for sensitive data.
