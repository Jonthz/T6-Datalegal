# DataConSentido Color Reference

## Source

Colors were extracted from the public DataConSentido website and approximated from the provided logo screenshot.

- Website: https://www.dataconsentido.com/
- Observed positioning: "Privacidad - Cumplimiento - Tecnologia"
- Observed context: Ecuador, LOPDP, verifiable evidence, DPO services, risk management, RAT/RID and DPIA.

## Website Palette

| Token | Hex / Value | Observed Use |

## Recommended Use In DataLegal

DataLegal should not be rebranded as DataConSentido. These colors should be used only as controlled visual inspiration for a future design pass.

- Keep DataLegal as a light, operational SaaS workspace.
- Use navy/teal accents for brand moments, active navigation, focus states and primary actions.
- Reserve green, amber and red for semantic status and risk meaning.
- Avoid copying the DataConSentido landing-page treatment directly into the app shell.
- Prefer flat, readable surfaces over decorative gradients for tables, forms and dashboards.
